# Stacks and Queues Implementations

## 📌 Overview
This directory contains C implementations of foundational linear data structures: **Stacks** and **Queues**. These files demonstrate both array-based and linked list-based approaches to handle LIFO (Last-In, First-Out) and FIFO (First-In, First-Out) data processing.

---

## 📂 Files Included

| File Name                | Description 
| :------------------------| :-----------------------------------------------|
| stack_using_array.c      | Stack implementation using a fixed/dynamic array.  
| stack_using_LinkedList.c | Stack implementation using a dynamic linked list. 
| circular_queue.c         | Queue implementation using a circular array buffer. 
| queue_using_LinkedList.c | Queue implementation using a dynamic linked list.
