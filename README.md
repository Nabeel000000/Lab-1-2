## 🎯 Objective

The primary objective of this repository is to build a strong foundation in computer science by implementing essential data structures and algorithms from scratch. These exercises are designed to develop critical problem-solving skills, improve understanding of memory management, and demonstrate the practical application of theoretical concepts to write efficient, optimized code.

## 📖 Overview

This repository contains my comprehensive collection of laboratory assignments and homework for the Data Structures course. The exercises focus heavily on low-level memory manipulation, data organization, and classic algorithmic problem-solving. While primarily written in C, it also incorporates C++ for specific algorithmic implementations.

## 🗂️ Topics Covered (Repository Structure)

The codebase is organized by topic, reflecting the progression of concepts covered in the course:

*   **`00_dynamic_memory/`** : Exercises covering pointers, dynamic allocation, and manual memory management.
*   **`01_recursion/`** : Classic algorithmic problems solved utilizing recursive functions.
*   **`02_linked_lists/`** : Various implementations of linked list data structures.
*   **`03_stacks_and_queues/`** : Implementations of LIFO (Stack) and FIFO (Queue) architectures.
*   **`04_sorting_searching/`** : Foundational algorithms for sorting arrays and efficiently searching for elements.
*   **`05_trees/`** : Implementations of hierarchical data structures, including Heaps, Binary Trees, Binary Search Trees, and AVL trees.
*   **`06_string/`** : Abstract Data Type (ADT) implementations for strings and string-based algorithmic challenges.
*   **`07_graphs/`** : Graph data structures (Adjacency Matrix, Adjacency List) and pathfinding/spanning algorithms (Dijkstra's, Kruskal's).
*   **`Homework/`** : Comprehensive additional assignments, including complex tasks like nested mathematical expression parsing.
