## Overview
This repository contains my laboratory assignments and homework for . The exercises focus on implementing fundamental data structures, memory management, and classic algorithmic problem-solving in C.

## Topics Covered (Repository Structure)
The codebase is organized by topic:

*   **`00_dynamic_memory/`**: Exercises covering pointers, allocation, and memory management.
*   **`01_recursion/`**: Algorithmic problems solved using recursive functions.
*   **`02_linked_lists/`**: Implementations of singly and/or doubly linked list data structures.
*   **`03_stacks_and_queues/`**: Stack and queue implementations and their practical applications.
*   **`04_sorting_searching/`**: Classic sorting (e.g., merge, quick) and searching algorithms.
*   **`05_trees/`**: Binary trees, search trees, and traversal methods.
*   **`06_string/`**: String ADT and string-based algorithmic challenges.
*   **`Homework/`**: Additional assignments, including nested mathematical expression parsing.
