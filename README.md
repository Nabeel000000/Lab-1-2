## Overview
This repository contains my laboratory assignments and homework for Data Structures cource. The exercises focus on implementing fundamental data structures, memory management, and classic algorithmic problem-solving in C.

## Topics Covered (Repository Structure)
The codebase is organized by topic:

*   **`00_dynamic_memory/`**: Exercises covering pointers, allocation, and memory management.
*   **`01_recursion/`**: Algorithmic problems solved using recursive functions.
*   **`02_linked_lists/`**: Implementations of linked list data structures.
*   **`03_stacks_and_queues/`**: Stack and queue implementations.
*   **`04_sorting_searching/`**: Classic sorting and searching algorithms.
*   **`05_trees/`**: Binary trees, search trees, and AVL.
*   **`06_string/`**: String ADT and string-based algorithmic challenges.
*   **`Homework/`**: Additional assignments, including nested mathematical expression parsing.
